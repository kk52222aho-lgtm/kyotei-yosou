## 3. コメントを数にする — 決め打ちを先に固定する

**LLM は使わん。**理由は2つ:
①既定モデルが腐ると再現でけへん → [[insight_free_llm_models_rot]]
②本文検品の精度は別ドメインで実測 25% やった → [[feedback_llm_inspection_limits]]
LLM は**この辞書が落ちた後の別の検定**であって、1回目の道具やない。

辞書(**結果を1行も見ずに、日本語の素の意味だけで書いた**):

| 向き | 語 |
|---|---|
| 強い(+1) | 良い・いい・上位・一番・力強・仕上が・バランス・合って(る/ます)・上がって(る/いる)・悪くない |
| 弱い(−1) | 今一つ・イマイチ・悪い・弱い・物足り・乗り難・掛からな・上がらな・合ってな・重い |
| 中立(0) | 普通・可もなく |

- `cmt_score` = (強い語の数 − 弱い語の数)
- `cmt_rank` = `cmt_score` の**レース内順位**(盤の走査と同じ形に落とす)
- `cmt_len` = 文字数(**偽薬やのうて名前付きの対照**。長さそのものが効く可能性がある)

🚨 「悪くない」は「悪い」を含む。**否定を先に潰してから数える**。
→ [[insight_same_word_body_or_part]](語の禁止リストは効かん、の同型)

### 辞書 v2 に差し替えた(同じ日。**着順は1行も見とらん**)

v1 を 2,304艇に当てたら**強弱ゼロが 35.7%**。中身を読んだら
「中堅レベル」「上向いた」「もう一足」「重たい」「足りない」みたいな
**常用語がまるごと抜けとった**。これは着順を見んでも分かる**語彙の穴**やから、
埋めるんは事後選択やない。埋めた後 26.7% まで下がった。

- 足した強: 上向い・十分・強め・効果はあった / 過去形の否定「悪くなかった」
- 足した弱: 重た・足りな・もう一足・失敗
- 足した中立: **中堅**(宮島の紙で一番出る言い回しで、意味は「並」)・変わらず・他艇と同じ
- 🚨 入れんかった: 「まずまず」「もう少し」= 向きが文脈で割れる /
  「調整」「点検」「整備」= **行為であって評価やない。全艇に出る**
  → [[insight_missing_reads_as_zero]](旗が全行に立つのは旗が無いのと同じ)

**判定は v2 一本でやる。**v1 でも判定したら2回検定になる(v1 は数だけ残す)。

## 4. 偽薬 — 同じ配管に必ず流す

[[insight_model_residual_is_a_weak_control]] のとおり、**偽薬を入れんかったら
モデルの手抜きを新発見として読む**。盤では nat_win が t=+17 で通ってしもうた。

| 流すもん | 通ったらどう読むか |
|---|---|
| 純ノイズ ×3 | 通ったら**器が壊れとる**。やり直し |
| コメントをレース塊ごと入替 ×2 | 通ったら**器が壊れとる** |
| **nat_win のレース内順位**(モデルに入っとる) | 直交化後に通ったら**直交化が効いとらん**。カナリア |
| 今レースの着順(答え) | **通らんかったら器が死んどる**。逆向きの点呼 |

相手は**モデルの残差やのうて「既存14特徴のレース内順位+モデル確率へ直交化した残差」**。
盤の `scan_all` と同じ相手にする(道具を揃えな比較でけへん)。

## 5. ⑥(オッズの外か)は**この検定では分からん**と先に書いとく

コメントが的中を上げても、**それが値段に入っとるかは別問題**や。
宮島の紙は誰でも無料で読める=群衆も読んどる可能性が高い。
⑥を測るんは `odds_timeseries` 側の仕事や。**本数を数えた(2026-09-23)**:

| | レース |
|---|---|
| odds_timeseries 全体 | 7,073 |
| **うち宮島** | **396**(2026-07-17〜09-22 の2ヶ月) |

**396レースでは何も言えん。**競艇の到達率は49%で、回収の話をするには
必要な市場の誤りが大きい([[insight_required_vs_observed_error]])。
n=396 やと偶然の振れの方が桁で大きい。
**ここで「エッジ」いう語は使わん。**⑥は「測っとらん」やのうて
**「今の在庫では測れん」**と書く。測れるようにするには宮島のオッズを
前向きに貯めるしかない(1場×12R/日で、年 2,400レース)。

## 6. 読み方(回す前に決める)

| 艇単位(主) | レース単位(従) | 読み方 |
|---|---|---|
| 直交化後 t が FWER 閾値超え | +が CI で0を跨がん | **本物の候補**。盤に載せて holdout で再確認 |
| t 超え | CI が0を跨ぐ | **想定どおり**(§2で本数不足と書いた)。艇単位を採る |
| t 超えん | +が出とる | **採らん**。レース単位は従やし本数も無い |
| t 超えん | 出とらん | **効かん**と書いて閉じる。LLM 版は別の検定として残す |
| 偽薬が1本でも通る | | **全部やり直し。**結果は読まん |

**符号が逆に出たら(「弱い」言うた艇の方が来る)使わん。**
測り方で符号が変わる量やから。→ [[feedback_landing_bias]]

## 7. 留保(先に書いとく)

- **1場だけや。**宮島で出ても他場で再現するかは**測れん**(他場に紙が無い)。
  1場で出た時点では「宮島の記者と場の運用」の性質かもしれん
- コメントは**場が採って紙が刷る**。途中で誰かが編集しとらんかは分からん
- 2022-01 より前は entries が無いんで測れん(紙は在るかもしれん)
- `cmt_score` の非欠測率は退避が終わってから数える。**0埋めはせん**

コーパスは完成した: **946開催日 / 67,977コメント(68,112艇の 99.8%)**。

## 艇単位(主)

| 列 | 訓練 4,572R | **holdout 3,459R** |
|---|---|---|
| 点呼: 着順(答え) | ★ +19.81 | ★ +17.35 |
| **cmt_score** | **★ +4.91** | **+2.36**(閾値2.75を超えず) |

- `cmt_score` は**符号が両方とも正**で、単独検定の1.96は超える。
  せやが多重性を入れた閾値は超えん

## 縮みは本数だけでは説明でけん

効果が安定しとったら t は √n で伸び縮みする。

    訓練 t=4.91 (4,572R) → 本数だけなら holdout は t=4.27 のはず
    実際は t=2.36。**本数で説明できる分より 1.91 小さい**

= 訓練の +4.91 には**規則を作った標本で採点した分の膨らみ**が入っとる。
→ [[feedback_in_sample_rule_scoring]]

## 閉じるけど、残るもん

1. **コーパスは資産や。**946日 / 67,977コメントは取り直さんでええ。
   次の検定(LLM で点数化する版)は**同じ holdout の上で**一発で回せる

   (そもそも他場に紙が無いんで測れん)
