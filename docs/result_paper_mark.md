# プロの予想屋(宮島の紙の記者)は盤より上か — 2026-09-24

**探索やない。**比べたんは**先に固定した3つの手**だけで、特徴も閾値も振っとらん。
せやから holdout の多重性は食わん(念のため訓練/holdout も別々に出した)。

対象 = 宮島 **8,021レース(2023-2026)**。2022 は `oof_base` が無い
(walk-forward の最初の年で前年データが足らずスキップ)。

## 結果(全期間 8,021レース)

| 手 | 本命的中 | 単勝ROI | 到達率 |
|---|---|---|---|
| ① 1号艇固定(予測が要らん) | 56.365% | 92.97% | +71.9% |
| **② モデル本命(盤)** | **57.935%** | **93.85%** | **+75.4%** |
| ③ **記者の◎(予想屋)** | 55.255% | 93.36% | +73.4% |

到達率 = (ROI − 払戻率)/(1 − 払戻率)。0%=無作為、100%=損益分岐。

    ③記者 − ②モデル の本命的中差  −2.680pt  CI95 [−3.613, −1.734](日クラスタ)

**プロの予想屋は盤に負けとる。しかも「1号艇を買うだけ」にも負けとる。**

## holdout でも同じ向き、しかも差が開く

| | 訓練 2023-24 (4,562R) | **holdout 2025-26 (3,459R)** |
|---|---|---|
| ① 1号艇固定 | 56.357% / ROI 92.42% | 56.375% / ROI 93.70% |
| ② モデル | 57.913% / ROI 93.41% | 57.965% / ROI 94.45% |
| ③ 記者 | 56.225% / **ROI 96.19%** | 53.975% / **ROI 89.62%** |
| ③−② 的中差 | −1.688pt CI[−2.895,−0.486] | **−3.990pt CI[−5.483,−2.477]** |

🚨 **記者のROIは訓練 96.19% → holdout 89.62% で7pt近く振れる。**
的中率は 56.2%→54.0% しか動いてへんのに ROI がこれだけ動く
= **ROI は的中率より桁で本数が要る量**。片方だけ見て「予想屋は儲かる/儲からん」と
言うたらあかん。

## なんで差が出たか — 記者は穴寄り

| | 記者の◎ | モデル本命 |
|---|---|---|
| 1号艇を選んだ率 | **67.7%** | 91.4% |

    食い違った 2,214レースでの的中: モデル 37.53% / 記者 27.82%

**モデルが1号艇を切る判断の方が当たっとる。**記者が1号艇を切った時は外しとる。

ただし **ROI はほぼ互角**(93.36 vs 93.85)。記者は的中を落とす代わりに配当を取っとる。
**的中率で負けてROIで並ぶ**= どっちの数字を看板にするかで見え方が変わる
→ [[feedback_sell_the_win]]

## 🚨 払戻率の取り違え(最初に自分で踏んだ)

初版は **「6艇フラット全買いの回収率」を払戻率と呼んで 68.2% を分母にしとった。**
これは払戻率やない——穴が過剰人気(w_i > p_i)やと均等買いは払戻率より下に出る。

正しくは `odds_timeseries` の **1/Σ(1/オッズ)**:

| | |
|---|---|
| 全24場 6,568レース(締切−3分) | 中央 **73.57%** / IQR 72.8-74.2% |
| 場ごとのばらつき | 73.29〜73.72%(ほぼ一定) |

表示オッズは切り捨てやから 1/オッズ が過大 → **この推定は低めに出る**。
公称(控除25%)= 75% と整合するんで、到達率の分母は **75%** にした。
→ [[insight_estimator_needs_ground_truth]]
