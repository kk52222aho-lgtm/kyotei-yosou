## 2. 予想される結末を先に書く

**最有力は R3 の kill、R1 は継続(判定つかず)。**

理由:
- **R3 は EV≥1.15 で発火する。**1日135件も出とるいうことは、
  そのEVはモデル確率とオッズの積で、モデルが強気に外しとる可能性が高い。
  過去の B4(3連単EV最大化=回収2〜52%で壊滅)と同じ形をしとる。
  **EVで穴を選ぶと大穴ばかり掴む**いうのは既に本プロジェクトで確定済みの死に方や
- **R1 は本命=1号の単勝。**単勝1号艇のフラット回収は 90.6% で、
  全ジャンル中で控除の壁に一番近い。そこからEVフィルタで少し削るだけやから、
  **CI が 100 を跨いだまま**になるのが自然や。N=1,236 でも足りん見込み
- R2 は N=188 で、CI上限<100 が出た時だけ kill。それ以外は何も言えん

**この3行を書いた時点で「惜しい」「N足す」は封じる。**条項は N 振り直しを要求しとる。
