# 第2の検定 — 学習した文字n-gramの上限(回す前に読み方を決める)

**2026-09-23 作成。モデルを1回も当てとらん時点で書いた。**

## なんでやるか

辞書版(v2)は holdout で通らんかった(艇単位 t=+2.36 < 閾値2.75、
レース単位 −0.029pt)。せやが**辞書が悪かったんか、文に情報が無いんかは
分けられん**と結果に書いた。それを分ける。

**辞書は「人が思いついた語」しか見とらん。**文字n-gramを学習させたら、
**語彙レベルで取れる情報の上限**が出る。これが取れんかったら、
「辞書の選び方が悪かった」いう言い訳は消える。

LLM をやる前にこれをやる理由:
- **決定論的で再現できる**(既定モデルが腐らん → [[insight_free_llm_models_rot]])
- **タダ**(枠を食わん → [[feedback_llm_quotas]])
- **上限**やから、これが0なら LLM の見込みも下がる

## 🚨 これは holdout への**2回目**の照会や

1回目(辞書版)で holdout を見とる。2回とも同じ盤で測るんやから、
**通った場合でも「2回のうち1回」であることを割り引いて読む。**
通らんかった場合は割り引く必要が無い(否定は多重性で強くならん)。

**3回目はやらん。**次に同じ holdout を見るんは LLM 版だけで、それで打ち止め。

## 器

| | |
|---|---|
| 入力 | `paper_comment.comment` の生文。**正規化は全角半角だけ** |
| 特徴 | 文字 n-gram (2〜4)、TF-IDF、`min_df=20`、上限 30,000 次元 |
| 当てる先 | **訓練期間だけ**の直交化残差(既存14特徴のレース内順位+モデル確率へ直交化したもん) |
| 学習 | Ridge(alpha は訓練内の GroupKFold=日 で選ぶ。**holdout は一切見ん**) |
| 判定 | 学習したスコアを**レース内順位**に落として、holdout の直交化残差に当てた t |
| 閾値 | 1回目と同じ FWER 5%(日クラスタ multiplier bootstrap、max\|t\|の95%点) |

**当てる先を「勝ち負け」やのうて直交化残差にするんは、1回目と相手を
揃えるため。**勝ち負けに当てたら、モデルが既に持っとる情報を学習し直すだけ。

## 偽薬(同じ配管に流す)

| 流すもん | 通ったらどう読むか |
|---|---|
| **訓練の残差をレース塊ごと入替してから学習** ×2 | 通ったら**配管が漏れとる**。やり直し |
| 純ノイズのレース内順位 ×2 | 通ったら器が壊れとる |
| **nat_win のレース内順位**(カナリア) | 直交化が効いとるかの点呼 |
| 着順(答え) | 通らんかったら器が死んどる |

🚨 **1回目と違う漏れ方があるんで、偽薬も1本足した。**
学習を挟むと「ラベルを見て特徴を選ぶ」経路ができる。
**ラベルを壊してから学習させて、それでも通るかを見る**のが唯一の点呼や。

## 漏れの経路を先に名指しとく

1. **選手の同定**: コメントは選手本人の言葉やから、書き癖で選手が割れるかもしれん。
   割れたら nat_win を学習し直すだけ。→ 相手が**直交化済み**やから素通りはせん
2. **節の重複**: 同じ節の同じ選手は似たコメントを何日も出す。
   → 訓練/holdout は**年で切っとる**(2022-2024 / 2025-2026)んで節は跨がん
3. **alpha 選びの漏れ**: GroupKFold の group を**日**にする。
   レース単位で切ったら同じ日の別レースが訓練と検証に割れる

## 読み方(回す前に決める)

| holdout の直交化 t | 読み方 |
|---|---|
| 閾値超え | **辞書が悪かった。**語彙に情報が在る。ただし**2回目の照会**やから割り引く。 次は「どの n-gram が効いたか」を人が読んで意味が通るか見る |
| 超えん(\|t\|<閾値) | **語彙レベルには情報が無い。**辞書のせいやない。 「コメントは効かん」を一段強く書ける。LLM 版の見込みも下げる |
| 偽薬が1本でも通る | **全部やり直し。**結果は読まん |
| 符号が負 | 使わん(測り方で符号が変わる量) |

## 先に書いとく留保

- **上限やのうて「文字n-gramの上限」や。**語順や含意を要る信号は取れん
- 訓練の当てはまりは**必ず良く出る**(30,000次元で残差に当てるんやから)。
  訓練側の数字は**器の点呼にしか使わん**。判定は holdout 一本
- 1場だけの話

# 結果(2026-09-23)。**規則は一切いじっとらん**

## 判定: **通った。辞書が悪かった**

| 列 | 訓練 4,572R ※器の点呼だけ | **holdout 3,459R ← 判定** |
|---|---|---|
| 点呼: 着順(答え) | ★ +19.81 | ★ +17.35 |
| **ngram学習スコア** | ★ +14.20 | **★ +4.07** |
| 偽薬 ラベル入替で学習1 | +0.87 | +1.43 |
| 偽薬 ラベル入替で学習2 | +0.31 | **+2.15** |
| 偽薬 natwin(カナリア) | +1.53 | −1.64 |
| 偽薬 ノイズ×2 | −1.63 / −0.84 | +1.23 / +0.30 |

FWER 5% 閾値 |t| > 2.67。TF-IDF 7,190次元 / alpha=1000 / 訓練内CV相関 +0.0149。

**辞書版は holdout で +2.36(閾値2.75)で落ちた。学習させたら +4.07 で通った。**
= **語彙レベルには情報が在る。1回目が落ちたんは辞書の選び方のせい。**

🚨 **訓練の +14.20 に √n の縮み検定を当てたらあかん。**訓練行は
モデルを当てはめた本人やから in-sample で、1回目(辞書版)とは意味がちがう。
v2 では訓練側は**器の点呼にしか使わん**と先に書いてある。

🚨 **偽薬2が +2.15 で、閾値 2.67 に近い。**規則どおり「超えてへん」で通すが、
近いことは書いとく。入替は訓練レースの中だけでやったが、**塊の中の位置(艇番)は
保たれる**んで、艇番に紐づく generic な成分は生き残る。
(艇番は直交化に入っとるんで素通りはせんはずやが、完全には潰せてへん)

## 効いた n-gram を人が読んだ(事前登録した次の手)

頻度200以上に絞った上位/下位。**意味が通る:**

| 来る側 | 来ん側 |
|---|---|
| 悪くない / 悪くな / 悪く | 合っていない / 合ってい / 合って |
| 足も良い / の足が良 / 足も | 少し弱 / 弱い / し弱 |
| 良い感じ / 良い感 | いない感 / ていな / いない |
| は全体的 / ンは全体 | ので / ので、 / する / する。 / たけど |

### 🚨 いちばん効いた発見は「行為の語」の**文法の形**やった

    「ペラ調整」    +0.00217  (n=1,674)
    「ペラを調整」  −0.00282  (n=3,084)   ← 符号が逆

**同じ「調整」でも、助詞が入るかで向きが逆。**
「ペラ調整のみ」= 足は出来とるから触るだけ /
「ペラを調整します」= 合うてへんから直す、いう意味になる。

辞書版では **「調整・点検・整備は行為であって評価やない。全艇に出る」いう理由で
明示的に外しとった。**それが間違いやった。
**「全行に出る語」やのうて「全行に出る語の、形の違い」に情報が在った。**
→ [[insight_same_word_body_or_part]] の別型(同じ語が形で割れる)

## 黄色信号: 機能語が重みを持っとる

来ん側の上位に **「ので」「する」「って」「たけど」** が並んどる。
内容語やのうて言い回しや。考えられる筋は2つ:

1. **言い回しが評価と結びついとる**(「〜ので、調整する」= 不足の説明)
2. **書き手/時期の癖を拾っとる**(誰の談話か、いつの紙かの代理)

2やと、盤の外の情報やのうて**選手の同定を学習し直しとる**だけかもしれん。
ただし相手は nat_win を含む14特徴へ直交化済みで、カナリアも −1.64 で沈んどる。

**次の検算(holdout は見ずに訓練だけでやる)**: 機能語だけを落とした版と、
内容語だけ落とした版を訓練内CVで比べる。内容語を落としても残るなら 2 の疑いが濃い。

## 🚨 これで holdout は打ち止め

v2 の冒頭に「3回目はやらん」と書いた。**通った以上、次は holdout の再照会やのうて
盤に載せて前向きに測る**。実務の大きさ(本命的中が何pt動くか)を知りたいなら、
**別の事前登録**を書いて前向きにやる。この holdout でもう一回測ったら3回目や。

# 事前登録した検算の結果(2026-09-24)。**holdout の判定は変えとらん**

## ① 選手の同定の疑い → **閉じた**

| | |
|---|---|
| 学習スコアのレース内順位 vs `nat_win` のレース内順位 | **r = −0.0024**(n=27,432) |
| コメント → `nat_win` の訓練内CV相関 | **+0.1890** |

コメント自体は選手の強さを **r=0.19 で当てられる**。せやのに
**直交化残差に当てた版は nat_win と無相関**。= 直交化が仕事しとる直接の証拠。

## ② 機能語/内容語の切り分け → **道具が分離でけんかった**

| | 次元 | 訓練内CV相関 |
|---|---|---|
| 全部 | 7,190 | +0.0149 |
| 内容語だけ(ひらがなのみを落とす) | 5,753 | +0.0144(**97%**) |
| 機能語だけ(漢字カナ入りを落とす) | 1,437 | +0.0113(**75%**) |

**足して100%を超える = 同じ情報の別の見方**やった。char n-gram に語の区別が無いんで
字種で代理したが、**これでは答えられん**。片方に決めずに「測れんかった」と書く。
分けるには形態素解析が要る(入っとらん)。→ [[feedback_incomparable_measurement]]

## ③ 🚨 疑ったんは俺の方で、**+4.07 は生き残った**

v2 で偽薬(ラベル入替で学習)が **+2.15** まで出とったんで、
「**学習した列の帰無分布は、固定した列のそれより裾が広いんちゃうか**」と疑うた。
偽薬を **2本 → 30本**に増やして測り直した(`src/test_paper_ngram_null.py`):

| | |
|---|---|
| 学習を挟んだ列の帰無分布(N=30) | 平均 **+0.16** / sd **0.96** / 最大\|t\| **2.22** |
| \|t\| の95%点 | **1.85**(v2 が使うた固定列の閾値 2.67 より**むしろ狭い**) |
| 本物 \|t\|=4.07 以上が出た偽薬 | **0/30** → 経験 p ≲ 0.033 |

**裾は広がっとらんかった。**v2 の +2.15 は2本しか引いてへんかったサンプルの裾や。
**疑いは晴れた。判定は据え置き。**

## ④ 年をまたぐと効かん → **時間のドリフトやのうて本数**

| 割り方 | 学習 | 採点 | 日クラスタ t |
|---|---|---|---|
| 年で割る | 2023(13,824艇) | 2024(2,268R) | **−0.30** |
| 年で割る | 2024(13,608艇) | 2023(2,304R) | **+0.26** |
| **日単位で無作為に割る** | 半分(13,722艇) | 2,285R | **−0.22** |
| **日単位で無作為に割る** | 半分(13,710艇) | 2,287R | **+0.95** |
| 2年ぶん全部 | 27,432艇 | holdout 3,459R | **+4.07** |

**無作為に割っても年で割っても同じくゼロ。**= 時期のドリフトやない。
**学習が 13.7k艇 → 27.4k艇 になって初めて出る。**

🚨 **これは朗報やのうて警告や。**半分にしたら消える信号は、**データの端で立っとる**。
7,190次元に13.7k標本やと ridge が拾えず、27.4kで拾える、いう regime の話で、
**上乗せの大きさは「ぎりぎり検出できる」程度**やいうこと。

→ **前向きで測るのが一段と大事になった。**holdout はもう2回見とる。
