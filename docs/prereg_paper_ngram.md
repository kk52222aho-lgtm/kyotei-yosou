## 0. これは勝ちやない

測るんは**予想精度**だけや。控除は動いてへんし、回収エッジ無しは確定しとる。
通っても「賭けたら勝てる」には一歩も近づかん。→ [[feedback_sell_the_win]]

## 1. なんで前向きにやるか

holdout(2025-26)は**2回見た**:

| | holdout の t | |
|---|---|---|
| 辞書版(v1/v2) | +2.36 | 閾値2.75を超えず → 棄却 |
| **文字n-gram 学習版** | **+4.07** | 閾値2.67を超えて通過 |

通過の側は検算もした(2026-09-24、holdout は見ずに訓練内だけ):

- 偽薬を2本→**30本**に増やして帰無を測り直し = 平均+0.16 / sd 0.96 / 95%点 1.85。
  **+4.07以上は 0/30**(p≲0.033)。固定列の閾値2.67より**むしろ狭い**
- 学習スコアと `nat_win` のレース内順位は **r=−0.0024**(選手の同定の疑いは閉じた)

🚨 **せやが、学習を半分(13.7k艇)にしたら消える**(年で割っても日で無作為に割っても
t≈0)。**ぎりぎりで立っとる信号**や。**holdout をもう一回見たら3回目**になる。
→ 残っとるんは前向きだけ。

## 3. 記帳の手順

`src/paper_daily.py` を毎朝回す(`KyoteiPaperDaily`)。

- 宮島が開催する日だけ。**その日の全レース・全艇**を記帳する
  (発火したレースだけやのうて全部。後から抽出条件を動かして解釈せんため)
- **着順も払戻も一切見ずに保存する。**紙には結果が刷られとるが、
  `collect_paper` は列として持たん作りや
- 各行に `recorded_at` と `model_sha` を残す。**締切前やったか / すり替えが無いかを
  後から検算できるように**
- 既に記帳した (date,rno,lane) は**上書きせん**。最初の記帳が証人
- 紙が出る時刻は実測済み: 2026-09-22 の紙は **11:47 の時点で 16:36 締切の R12 の
  コメントまで全部在った**(最終レースの5時間前)

## 4. 判定に使う統計 — **先に固定する**

holdout と**同じもん**を使う。道具を揃えな比較でけへん。

    z = ngram_score の**レース内順位**(race_z)
    相手 = 既存14特徴のレース内順位 + モデル確率 へ直交化した残差
    統計 = 日クラスタの multiplier bootstrap で max|t| の95%点(FWER 5%)

偽薬を**同じ配管に**流す(1本でも通ったら結果は読まん):

| | |
|---|---|
| 純ノイズのレース内順位 ×3 | 種は判定日に決める |
| `nat_win` のレース内順位(カナリア) | 直交化が効いとるかの点呼 |
| 着順(答え) | 通らんかったら器が死んどる |

## 5. 何本で判定するか — **先に計算した**

holdout は **3,459レースで t=+4.07**。効果が同じ大きさなら t は √n で動く:

    2.8σ に要る本数 = 3,459 × (2.8/4.07)² = **1,637レース**

宮島は年200日前後 × 12R = 約2,400レース/年。→ **約8ヶ月**。

- **真の効果が半分やったら 4倍の本数が要る(約2.7年)。**
  §1 のとおり「ぎりぎりで立っとる」信号やから、**縮む方に賭けとくべき**や
- **途中で覗かん。**中間判定はやらん。`n=1,637レース` に達した日に**1回だけ**測る
- そこまでに達せんかったら、**その時点では何も言わん**

## 6. 読み方(判定日より前に決める)

| 直交化 t | 読み方 |
|---|---|
| FWER 5% 閾値を超え、符号が**正** | **前向きで再現した。**盤に載せる候補。それでも「金」の話やない |
