## 1. ルール(凍結)

```
発火条件:
  ・モデル本命が1号艇やない(FLB)
  ・その本命艇に T-10 と T-1 の両方のオッズがある
  ・log( O(T-1) / O(T-10) ) < 0        ← 値が下がった = 「縮」
買い目: その本命艇の単勝1点、T-1 のタイミングで記録
```

対照として**同じレース集合**で以下も必ず記録する:

| | |
|---|---|
| 広群 | 同じ条件で `log(...) >= 0` の本命艇 |
| **1号艇固定** | そのレースの1号艇単勝(**予測が要らん手**) |

## 2. 決着可能性 — 数字を見る前に書く

**ROI での合格は、この設計では起こらん。**

1件あたりの払戻SDは **1.56**(後ろ向きの実測)。点推定 102.6% として:

| N | SE | CI下限が100%を超えるのに要る点推定 |
|---|---|---|
| 300 | 9.0pt | 118% |
| 600 | 6.4pt | 113% |
| 1,000 | 4.9pt | 110% |
| **13,800** | 2.6pt | **105%** |

**真値が 102.6% やとしたら、CI下限を100%より上へ出すには N≈13,800 = 約7年要る。**
縮の発火は **5.5件/日**や。

→ **ROIを主要評価にしたらあかん。**それは7年後にしか答えが出ん。

### 主要評価は「向き」にする

**縮群 − 広群 の回収率差**なら決着する。後ろ向きの差は **+10.5pt**。
差のSEは両群 N=850 ずつで約 7.6pt。**N=850/群 ≒ 150日**で符号が確定する。

| | 判定基準 | 要るN | 見込み日数 |
|---|---|---|---|
| **主要: 縮 − 広 の差** | 差の95%CIが0を跨がん | 850/群 | **約150日** |
| 副次: 縮の絶対ROI | CI下限 ≥ 100% | 13,800 | **約7年 = 事実上不可能** |

**最有力の結末: 「向きは確定した。儲かるかは未確定。」**
これを先に書いとかんと、150日後に「惜しい」「N足す」が必ず出る。

## 3. 出口

1. **縮 − 広 の差の CI が 0 を跨がず正** → 機構は前向きでも確定。
   **やが張る根拠にはならん**(絶対ROIが未確定やから)。次は容量と執行の話へ
2. **差の CI が 0 を跨がず負**(広>縮) → 後ろ向きの向きが再現せんかった。**閉じる**
3. **差の CI が 0 を跨ぐ** → 継続。**閾値も群の定義も動かさん**
4. **縮の絶対ROI が N≥600 で 90% を割る** → kill。機構が正でも張れんことが確定
