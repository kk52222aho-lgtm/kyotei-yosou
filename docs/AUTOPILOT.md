## 門が鳴った時の行き先

**4枚ある。鳴ったやつだけ見ればええ。**

1. **RC** — タスクの戻り値が0やない。だいたい push か権限
2. **予定** — Ready やのに次回が過去。Windows Update の再起動でログイン前に止まるとこれ
3. **成果物** — 走ったのに書いとらん。ログが別プロセスに握られとる時に出る
4. **収穫**(`yield_watch.py`)— **走っとるのに何も得とらん**。
   「収穫0 が N日 かつ 残件>0」で鳴る。**残件0なら鳴らん**(終わった仕事を赤く塗らんため)

    門の出どころ: `C:/dev/edge-ledger/tools/task_health.py` と `tools/yield_watch.py`
    ログ: `C:/dev/edge-ledger/logs/task_health.log`

## 触る時の落とし穴(全部実際に踏んだ)

- **束は自分の形について嘘をつく。**`train.py` は保存前に宣言列数とモデルの
  入力数を突き合わせる。外したらあかん

  してある。計算を2か所に置いたらズレる

  積んどるモデルの出どころが消える(git に入れてある)

  1分刻みの探査が38回 `database is locked` でこけた
